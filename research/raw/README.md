# Raw simulation data

`results_full_sweep.zip` contains the 110 run outputs from the full sweep (including `.sca`, `.vec`, and `.vci` files). `fixed60_core.zip` contains 25 selected `.sca` scalar files from the earlier 60-node baseline and attack-condition experiments used in the combined analysis.

The original outputs contain generated simulation data and are kept compressed to avoid filling the repository with thousands of loose generated files. Extract only when re-processing or inspecting raw observations. The processed CSV files in `../analysis/` were generated from these sources.
